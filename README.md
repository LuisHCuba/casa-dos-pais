# Casa dos pais

Projeto do HomeByMe convertido em código: modelo JSON (paredes, cômodos, portas, janelas e 76 móveis), visualizador 3D/2D em Three.js e exportação da planta em SVG.

```bash
npm install
npm run dev     # visualizador
npm run plan    # out/plan.svg
```

Os detalhes do modelo e as convenções estão em `CLAUDE.md`.
